Florilegium namespace

Namespace IRI: https://w3id.org/florilegium/ns#, conventionally abbreviated fl:.

Florilegium is a reading workspace whose records are W3C Web Annotations with a few properties of its own. This page is where the namespace resolves. The JSON-LD context that defines the short names is a separate, versioned document:

  • https://w3id.org/florilegium/ns/v1.jsonld (version 1)

A published context version is not edited. New terms arrive in a new version, so a record keeps the meaning it was written with.
