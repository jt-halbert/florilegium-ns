Florilegium code-understanding vocabulary, version 1

Namespace IRI: https://w3id.org/florilegium/code-understanding/v1#, conventionally abbreviated und:.

code-interrogator separates rebuildable structural facts (code:) from cumulative semantic understanding. This vocabulary defines the append-only understanding records, immutable revisions, explicit human verification standing (draft vs. verified), content-addressed anchors (blobHash, sigHash, bodyHash), and cross-record links stored in the urn:ci:understanding Named Graph.

  • https://w3id.org/florilegium/code-understanding/v1.ttl: this vocabulary in Turtle (OWL 2)

This version does not change once persisted records or projections name its bytes. Changed terms arrive in a new version at a new address. Version 1 is a draft until frozen by its first published release.

Terms

und:UnderstandingRecord Class: Understanding record
A durable lineage of cumulative semantic understanding about a codebase, pointing to its current immutable revision.
und:UnderstandingRevision Class: Understanding revision
One immutable revision of an understanding record, carrying its standing status, summary, Markdown body, provenance, and code anchors.
und:Anchor Class: Anchor
A content-addressed link tying an understanding revision to a repository, cluster, file, symbol, or line range with exact hashes for mechanical staleness detection.
und:SubsystemSummary Class: Subsystem summary
An understanding revision describing the responsibility and boundaries of a subsystem or cluster.
und:ArchitecturalDecision Class: Architectural decision
An understanding revision recording why a design choice was made and what trade-offs it entails.
und:Invariant Class: Invariant
An understanding revision stating a rule or constraint that must always hold in the codebase.
und:DataFlow Class: Data flow
An understanding revision tracing how data or control flows across components.
und:Gotcha Class: Gotcha
An understanding revision warning about subtle behavior, edge cases, or pitfalls.
und:EntryPointGuide Class: Entry-point guide
An understanding revision explaining how execution enters and boots the system.
und:GlossaryTerm Class: Glossary term
An understanding revision defining domain terminology used in the codebase.
und:OpenQuestion Class: Open question
An understanding revision capturing an unresolved ambiguity or question for future investigation.
und:ExternalContext Class: External context
An understanding revision recording outside constraints, upstream dependencies, or operational context not visible in source bytes alone.
und:RepoAnchor Class: Repository anchor
An anchor scoping an understanding revision to the repository as a whole.
und:ClusterAnchor Class: Cluster anchor
An anchor binding an understanding revision to a Leiden code:Cluster.
und:FileAnchor Class: File anchor
An anchor binding an understanding revision to a code:File and its blob SHA-256 digest.
und:SymbolAnchor Class: Symbol anchor
An anchor binding an understanding revision to a code:Symbol with exact signature and body AST hashes.
und:LineRangeAnchor Class: Line-range anchor
An anchor binding an understanding revision to a specific line span inside a code:File.
und:currentRevision Property, a link: current revision
Links an und:UnderstandingRecord to its latest immutable und:UnderstandingRevision.
und:record Property, a link: record
Links an und:UnderstandingRevision back to its owning und:UnderstandingRecord.
und:prevRevision Property, a link: previous revision
Links an und:UnderstandingRevision to the immediately preceding revision in its append-only history chain.
und:hasAnchor Property, a link: has anchor
Links an und:UnderstandingRevision to one of its content-addressed und:Anchor nodes.
und:target Property, a link: target
Links an und:Anchor to the extracted code:Symbol, code:File, or code:Cluster IRI it grounds.
und:explains Property, a link: explains
Indicates that one understanding record explains another record or topic.
und:dependsOn Property, a link: depends on
Indicates that one understanding record depends on another record's premise or decision.
und:contradicts Property, a link: contradicts
Indicates that one understanding record conflicts with or challenges another record.
und:refines Property, a link: refines
Indicates that one understanding record narrows or adds detail to another record.
und:supersedes Property, a link: supersedes
Indicates that one understanding record replaces an earlier record.
und:appliesTo Property, a link: applies to
Indicates that an understanding record applies to a broader record, subsystem, or invariant.
und:recordId Property, a value: record ID
Stable UUIDv7 identifier of an und:UnderstandingRecord.
und:revisionId Property, a value: revision ID
Stable UUIDv7 identifier of an immutable und:UnderstandingRevision.
und:kind Property, a value: kind
Normalized understanding record kind (subsystem_summary, architectural_decision, invariant, data_flow, gotcha, entry_point_guide, glossary_term, open_question, external_context).
und:status Property, a value: status
Explicit verification standing of a revision: draft, verified, contested, or superseded.
und:summary Property, a value: summary
Concise single-paragraph summary of an understanding revision.
und:bodyMd Property, a value: body (Markdown)
Full Markdown body of an understanding revision.
und:confidence Property, a value: confidence
Author-supplied confidence score (0.0 to 1.0) on an understanding revision.
und:verifiedBy Property, a value: verified by
Explicit authority that promoted a revision to verified (chat_confirmed or cli).
und:verifiedAt Property, a value: verified at
RFC 3339 UTC timestamp when the revision was promoted to verified.
und:commitShaAtWrite Property, a value: commit SHA at write
Git HEAD commit SHA observed when the revision was written.
und:freshness Property, a value: freshness
Mechanical staleness state of an anchor: fresh, relocated, stale_body, stale_signature, or orphaned.
und:isEffectiveFresh Property, a value: is effectively fresh
Whether an anchor is fresh or cleanly auto-relocated with intact signature and body hashes.
und:anchoredCommit Property, a value: anchored commit
Git HEAD commit SHA recorded on an und:Anchor when captured.
und:anchoredBlobHash Property, a value: anchored blob hash
File blob SHA-256 recorded on an und:Anchor.
und:anchoredSigHash Property, a value: anchored signature hash
Normalized symbol signature SHA-256 recorded on an und:Anchor.
und:anchoredBodyHash Property, a value: anchored body hash
Normalized symbol body SHA-256 recorded on an und:Anchor.
und:driftSummary Property, a value: drift summary
Human-readable explanation of how the anchored code changed relative to its stored hashes.
und:filePath Property, a value: file path
Repository-relative POSIX path recorded on an und:Anchor.
und:symbolKey Property, a value: symbol key
Symbol key recorded on an und:Anchor.
und:clusterId Property, a value: cluster ID
Cluster ID recorded on an und:Anchor.
