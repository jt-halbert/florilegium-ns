Florilegium check vocabulary, version 1

Namespace IRI: https://w3id.org/florilegium/check/v1#, conventionally abbreviated chk:.

Florilegium is a reading workspace. It can check a draft or a saved record against what a place already holds. This page defines the terms those checks use while they run: the facts the software states about the records it captured for one check, and what a check declares about itself. None of these terms is ever written into a record, and a check gives nothing standing. The records' own terms are in the Florilegium namespace.

  • https://w3id.org/florilegium/check/v1.ttl: this vocabulary in Turtle (OWL 2)

This version does not change once a place's check profile names its bytes. Changed terms arrive in a new version at a new address. Version 1 is a draft until the first kept place that names it.

The file also states that fl:claim, fl:commitment, fl:evidence and fl:norm are each a kind of chk:Contribution. That classification is used only inside a check.

Terms

chk:Contribution Class: Contribution
A typed contribution drawn from an exact passage of a retained source: a reading, a claim, an evidence assessment or a commitment.
chk:Check Class: Check
One captured check: its subject and the date it assumes, if any.
chk:subject Property, a link: subject
The annotation the check is about: a draft that has not been saved, or one exact saved revision.
chk:asOf Property, a value: as of
The calendar date the person chose for date checks. Never today's date by default.
chk:inScopeAs Property, a link: in scope as
Why a saved revision was captured: it holds standing (chk:Standing), the person selected it for comparison (chk:Selected), or the subject refers to it (chk:Referenced).
chk:Standing Named value
chk:Selected Named value
chk:Referenced Named value
chk:adoptedFor Property, a value: adopted for
The exact revision is what the decision now standing on its question adopts, for the named purpose. Stated by the service from the place's decision heads; a later rejection removes it.
chk:rejectedFor Property, a value: rejected for
The exact revision is what the decision now standing on its question rejects, for the named purpose.
chk:otherVersionAdoptedFor Property, a value: other version adopted for
Another revision of this annotation's lineage, not this one, is adopted for the named purpose.
chk:alternativeAdoptedFor Property, a value: alternative adopted for
A different annotation on the same question, not this one, is adopted for the named purpose.
chk:current Property, a value: current
Whether this exact revision is its author's current wording. False when newer wording exists.
chk:authorWithdrew Property, a value: author withdrew
Whether the author has withdrawn the annotation this revision belongs to. Separate from currency and from standing.
chk:targetVerified Property, a value: target verified
Whether the service found the annotation's sources retained in this place with matching digests, and its quoted text at the stated position.
chk:code Property, a value: code
The stable code a finding of this check carries.
chk:kind Property, a link: kind
chk:Structural: the finding follows from the records alone. chk:Heuristic: a candidate for the person to compare, decided by nothing here.
chk:Structural Named value
chk:Heuristic Named value
chk:blocksSaving Property, a value: blocks saving
Whether the same condition is refused when saving. The check reports it; the refusal is the save path's own.
chk:aboutValue Property, a value: about value
On a shape whose focus is a body: the finding is about the annotation reported as its value.
chk:appliesTo Property, a link: applies to
The body type whose subjects this check examines.
chk:needsAsOf Property, a value: needs as-of date
Whether the check runs only when the person has chosen a date.
