If the address you followed begins https://w3id.org/florilegium/id/, it is an identifier, not a page. It names one record, or one description of a converted document, in somebody's own Florilegium place.

  • The identifier is made from a hash of the thing it names. It lets two copies of the same record be recognised as the same record.
  • The thing itself is kept in that person's place. It is not stored here, and this site cannot tell you whether it exists.
  • To see what an identifier names, you need the place it belongs to, or an export of it. An export's manifest.json maps each identifier to the file that holds it.

Visiting this address did send the identifier to this web host, as any web request does. It sent nothing else.

For the vocabulary Florilegium's records use, see the namespace page.
