Florilegium code vocabulary, version 1

Namespace IRI: https://w3id.org/florilegium/code/v1#, conventionally abbreviated code:.

code-interrogator is part of the Florilegium ecosystem for strictly read-only, polyglot codebase interrogation. This vocabulary defines the deterministic structural facts extracted statically into the rebuildable urn:ci:extracted and urn:ci:meta Named Graphs (files, symbols, dependency edges, Leiden architectural clusters, and documentation pitfalls). Cumulative semantic notes live in the separate code-understanding vocabulary.

  • https://w3id.org/florilegium/code/v1.ttl: this vocabulary in Turtle (OWL 2)

This version does not change once persisted records or projections name its bytes. Changed terms arrive in a new version at a new address. Version 1 is a draft until frozen by its first published release.

Terms

code:Symbol Class: Symbol
A named definition extracted deterministically from a source file (function, method, type, trait, constant, or impl block).
code:File Class: File
A repository file discovered inside the read-only path jail and indexed by content hash.
code:Cluster Class: Cluster
An architectural subsystem community discovered by deterministic Leiden clustering over the extracted dependency graph.
code:DocPitfall Class: Documentation pitfall
A stale or broken code/path reference detected mechanically in repository documentation.
code:ExternalDependency Class: External dependency
A third-party or standard-library target referenced by an internal file or symbol outside the repository.
code:ExtractedEdge Class: Extracted edge
A reified dependency edge carrying its source, target, kind, provenance class, and confidence score.
code:Function Class: Function
A free or top-level function definition.
code:Method Class: Method
A method or constructor associated with a class, struct, receiver, trait, or impl block.
code:Class Class: Class
A class or record type definition.
code:Struct Class: Struct
A struct type definition.
code:Interface Class: Interface
An interface type definition.
code:Trait Class: Trait
A trait definition.
code:Enum Class: Enum
An enumeration type definition.
code:Impl Class: Impl
An implementation block attaching methods or trait implementations to a type.
code:TypeAlias Class: Type alias
A type alias or typedef declaration.
code:Constant Class: Constant
A module-level or type-level constant definition.
code:dependsOn Property, a link: depends on
Deterministic structural dependency between two repository symbols or files. Materialized for EXTRACTED edges to support native SPARQL property-path traversal.
code:calls Property, a link: calls
A deterministic (EXTRACTED) call from one symbol to another internal symbol.
code:callsAmbiguous Property, a link: calls (ambiguous)
A heuristic or unresolved (AMBIGUOUS) candidate call edge kept separate from deterministic code:dependsOn closure.
code:ambiguousDependsOn Property, a link: ambiguous depends on
A non-deterministic (AMBIGUOUS) dependency candidate kept separate from deterministic code:dependsOn closure.
code:importsInternal Property, a link: imports internal
An import or include edge targeting another file within the same repository.
code:importsExternal Property, a link: imports external
An import or include edge targeting an external library or standard-library package.
code:inherits Property, a link: inherits
An inheritance or extension relationship between types.
code:implements Property, a link: implements
An interface or trait implementation relationship.
code:tests Property, a link: tests
A static test coverage link from a test symbol or test file to a production symbol or file.
code:defines Property, a link: defines
A containment link from a file or scope to a symbol defined within it.
code:referencesSchema Property, a link: references schema
A dependency from code to a schema, migration, or contract definition.
code:inFile Property, a link: in file
The repository file (code:File) in which a symbol or documentation pitfall resides.
code:inCluster Property, a link: in cluster
The Leiden architectural cluster (code:Cluster) to which a symbol belongs.
code:edgeSource Property, a link: edge source
The source node of a reified code:ExtractedEdge.
code:edgeTarget Property, a link: edge target
The target node or external dependency of a reified code:ExtractedEdge.
code:filePath Property, a value: file path
Repository-relative POSIX path of a file or symbol's defining file.
code:symbolKey Property, a value: symbol key
Stable language-neutral identifier of a symbol (<lang>:<rel_path>::<qualname>).
code:name Property, a value: name
Short unqualified identifier name of a symbol or external dependency.
code:qualname Property, a value: qualified name
Scope-qualified name of a symbol within its file.
code:kind Property, a value: kind
Normalized lowercase symbol kind (function, method, class, struct, interface, trait, enum, impl, type, const) or pitfall kind.
code:language Property, a value: language
Canonical lowercase programming or markup language name (python, rust, go, typescript, etc.).
code:role Property, a value: role
Classified repository file role (source, test, docs, config, build, schema, generated).
code:blobHash Property, a value: blob hash
Content-addressed SHA-256 digest of the file bytes on disk.
code:lineCount Property, a value: line count
Number of lines in an indexed file.
code:churn90d Property, a value: 90-day churn
Number of git commits touching the file in the last 90 days.
code:startLine Property, a value: start line
1-based inclusive starting line number of a symbol or pitfall.
code:endLine Property, a value: end line
1-based inclusive ending line number of a symbol.
code:pageRank Property, a value: PageRank
Deterministic PageRank centrality score computed over EXTRACTED dependency edges.
code:betweenness Property, a value: betweenness
Brandes betweenness centrality score computed over EXTRACTED dependency edges.
code:inDegree Property, a value: in-degree
Number of incoming EXTRACTED dependency edges targeting a symbol.
code:outDegree Property, a value: out-degree
Number of outgoing EXTRACTED dependency edges leaving a symbol.
code:sigHash Property, a value: signature hash
Normalized AST SHA-256 digest of a symbol's signature, used for staleness detection.
code:bodyHash Property, a value: body hash
Normalized AST SHA-256 digest of a symbol's body, used for staleness detection and relocation.
code:isEntryPoint Property, a value: is entry point
Whether a symbol is classified as an executable repository entry point.
code:entryRank Property, a value: entry rank
1-based ranking of an executable entry point by source tier and downstream reachability.
code:clusterId Property, a value: cluster ID
Stable cluster identifier (e.g. cluster_0).
code:autoLabel Property, a value: auto label
Deterministic short label generated from a cluster's dominant directory and hub symbols.
code:verifiedTitle Property, a value: verified title
Human-confirmed title overriding a cluster's generated label.
code:algorithm Property, a value: algorithm
Community detection algorithm identifier (leiden).
code:memberCount Property, a value: member count
Number of graph nodes assigned to a cluster.
code:cohesionScore Property, a value: cohesion score
Fraction of incident edge weight remaining inside a cluster (0.0 to 1.0).
code:edgeKind Property, a value: edge kind
Normalized dependency edge kind on a reified code:ExtractedEdge.
code:provenanceClass Property, a value: provenance class
Epistemic class of an extracted edge (EXTRACTED, INFERRED, or AMBIGUOUS).
code:confidence Property, a value: confidence
Numeric confidence score (0.0 to 1.0) attached to a reified edge.
code:severity Property, a value: severity
Severity level reported on a code:DocPitfall (info, warning, error).
code:targetRef Property, a value: target reference
Unresolved symbol or path token cited by a code:DocPitfall.
code:message Property, a value: message
Human-readable diagnostic description of a code:DocPitfall.
code:repoType Property, a value: repository type
Inferred software classification of the indexed repository (cli, library, web_service, monorepo, infrastructure, scripts).
code:commitSha Property, a value: commit SHA
Git HEAD commit SHA recorded for an indexing snapshot.
code:branch Property, a value: branch
Git branch name recorded for an indexing snapshot.
code:isDirty Property, a value: is dirty
Whether the working tree had uncommitted modifications when the snapshot was indexed.
